================================================================================
TROUBLESHOOTING DELIVERY ORDERS SYNC
================================================================================

ISSUE: Delivery Orders sync not starting while others work

SOLUTION APPLIED:
- Using venv's pythonw.exe (required for Django dependencies)
- Set working directory with /D parameter
- Using absolute paths for both pythonw.exe and script

================================================================================
WHY VENV'S PYTHONW.EXE?
================================================================================

Unlike the other sync scripts, delivery orders sync uses Django, which requires:
- Django packages installed in venv
- Django settings module
- Database connections

That's why we need: venv\Scripts\pythonw.exe
Instead of: pythonw.exe (system Python)
